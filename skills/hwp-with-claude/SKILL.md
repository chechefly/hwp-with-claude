# 한글(HWP) 파일 채우기·편집

`hwp` MCP 서버(도구 이름이 `hwp_`로 시작)를 통해 한글 파일을 워드처럼 직접 다룬다.
서버가 안 보이면 사용자에게 "Claude Code 재시작 후 hwp MCP 로드 필요"를 안내한다.

## ★v1.0 엔진: 편집은 XML 직접 편집으로 통일
- `hwp_open`이 **XML 엔진**으로 연다: `.hwpx`는 그대로, `.hwp`는 같은 폴더에 `.hwpx` 작업본을 자동 생성(1회 변환) 후 XML로 편집. **`hwp_save` 시 원본 `.hwp`에 자동 반영**된다(작업본 `.hwpx`도 남음 — 관공서는 hwpx 제출도 대부분 가능).
- XML은 표 구조(주소·병합·내용)를 100% 정확히 읽으므로 **"이 폼은 되나?"라는 문제가 없다**. 결과의 `OK(t0 r1c4)`는 "표0(1번째 표)의 r1c4 셀에 확실히 기입됨"이라는 뜻(가짜 성공 없음).
- **미지원(XML 모드)**: `hwp_insert_text`·`hwp_list_fields`·`hwp_fill_fields`·`hwp_show_window` → 대신 `hwp_fill_by_label`/`hwp_replace` 사용, 확인은 `hwp_render`.
- 한/글(COM)은 변환·렌더에만 쓰이므로 창이 뜨지 않고, 파일 잠금도 없다.

## 황금 규칙 (공적·행정 문서 → 안정성·가역성 최우선)
1. **원본 보존**: 항상 사본을 만들어 작업한다. (예: `cp 원본.hwp 작업본.hwp`) — 원본 경로에 직접 저장하지 말 것.
2. **가역성(되돌리기) 보장**: `hwp_open`·`hwp_save`·`hwp_save_as`는 원본을 `.hwp_backups/`에 **자동 백업**한다(응답에 백업 경로 표시). 잘못되면 `hwp_list_backups` → `hwp_restore_backup`으로 **언제든 원상복구**한다. 사용자에게 "되돌릴 수 있다"는 점을 알린다.
3. **구조 먼저 파악**: 표는 절대 추측으로 채우지 말고 `hwp_table_map`으로 셀 주소를 먼저 읽는다.
4. **채운 뒤 눈으로 검증**: `hwp_render`(기본 `pages="all"`) 호출 → **이미지가 결과에 바로 담겨 오므로 그대로 보고** 값이 올바른 칸에 들어갔는지 확인한다(Cowork/클라우드에서도 됨, 별도 Read 불필요). **이 검증 단계를 생략하지 말 것.** ※표가 **2페이지 이후**에 있는 폼이 많다(1페이지가 표지·안내면 빈 것처럼 보임) → **반드시 전체 페이지를 보라**(1페이지만 보고 "표 없다"고 오판 금지).
5. 실제 데이터는 사용자에게 받는다. 테스트라면 그럴듯한 더미로 채우되 무엇을 넣었는지 보고한다.
6. **되돌리기 절차**: `hwp_list_backups(원본경로)`로 백업 확인 → `hwp_restore_backup(백업, 원본)`. 복원 전 현재 상태도 자동 백업되므로 복원 자체도 안전하다.
7. **★작업 끝나면 반드시 `hwp_close`**: 문서가 열려 있는 동안 그 .hwp 파일은 **사용자가 못 여는 읽기전용(잠금)** 상태다. 저장·검증이 끝나면 **항상 `hwp_close`를 호출**해 파일을 사용자에게 반납할 것. (닫으면 잠금 해제됨) — 이걸 빼먹으면 사용자가 "파일이 안 열려요" 하게 된다. 대량 편집 중이 아니면 저장 직후 닫아라.

## 표준 작업 흐름
```
1. (사본 생성)
2. hwp_open(path)                     # 전체 텍스트 반환 → 라벨/값 파악 (이게 제일 신뢰됨)
3. 채우기 (★우선순위 순):
   - ★hwp_fill_by_label({라벨: 값})   # ← 1순위. 라벨을 찾아 옆칸에 채움. table_map이 셀을 못 읽는 폼도 됨
   - hwp_check([라벨...])              # □ 체크박스 → ☑
   - hwp_check_after(키워드)           # 동의서식 ☐(특수문자) → ☑
   - hwp_set_cells(idx, {주소:값})     # (보조) table_map으로 주소가 잘 읽히는 폼일 때
   - hwp_replace / hwp_insert_text     # 자리표시자·일반 텍스트
4. hwp_render("all" 또는 "2") → 반환 PNG를 Read로 확인 → 틀리면 재작업
5. hwp_save() 또는 hwp_save_as(path, "HWP"/"HWPX"/"PDF")
6. hwp_close()   # ★파일 잠금 해제(사용자 반납)
```

## ★라벨로 채우기 `hwp_fill_by_label` — 가장 쉽고 범용적 (1순위)
사람처럼 "라벨 옆 칸에 쓰는" 방식. **셀 주소·병합·컨테이너 타입을 몰라도 됨.**
`hwp_table_map`이 셀을 빈 문자열로만 반환하는 폼(관공서 서식에 흔함)에서도 동작한다.
```
hwp_fill_by_label({
  "기 업 체 명": "위빌리브",
  "대  표  자": "이선호",
  "종 업 원 수": "5"
})
```
- **라벨은 `hwp_read_text`에 보이는 그대로** 넣는다(공백은 자동 유연 매칭 — "기 업 체 명"도 "기업체명"도 됨).
- `direction="auto"`(기본): 라벨 셀의 **오른쪽 칸 → 없으면 아래 칸**에 자동 기입(병합 감안, XML이라 정확).
- **양식+작성예시가 같이 있는 문서**(관공서에 흔함): `table=1`(1번째 표=빈 양식)을 주면 **예시를 절대 안 건드림**. `hwp_table_map`으로 몇 번째 표가 빈 양식인지 먼저 확인.
- **결과는 정직하다**: `OK(t0 r1c4)`=확실히 기입됨. `라벨 못 찾음`/`인접 칸 없음`=안 들어간 것 → 아래 "수동입력 안내"로 사용자에게 알려준다.
- 같은 라벨이 여러 개면 `nth`(몇 번째) 또는 `table`(몇 번째 표)로 구분.
- 채운 뒤 **hwp_render로 눈으로 확인**. 위치가 어긋났으면 `hwp_table_map`으로 주소 보고 `hwp_set_cells(cells={"r1c4":"값"})`로 정확 지정.
- **읽기전용 .hwp도 자동 처리**: 다운로드한 관공서 서식이 읽기전용이어도 자동 해제된다(원본 보존 위해 사본 작업 원칙은 그대로).

## ★자동으로 안 되는 칸 → 사용자에게 "수동입력 안내" (정직 우선)
어떤 칸이 `수동입력 필요`/`라벨 못 찾음`으로 나오거나, 렌더로 봤을 때 값이 엉뚱한 데 들어갔으면 — **억지로 넣지 말고** 사용자에게 **정확히 어디에 뭘 넣을지** 알려준다. 공적 문서는 틀리게 채우는 것보다 "여기에 이걸 넣으세요"가 안전하다.
- 되는 칸은 자동으로 채워 저장하고, **안 되는 칸만** 아래처럼 안내:
  > 아래 칸은 자동입력이 안 되니 직접 채워주세요(파일은 이미 저장됨):
  > - **대표자 성명** 칸 → `홍길동`
  > - **사업장 주소** 칸 → `서울시 강남구 …`
  > 한/글에서 해당 칸 클릭 → 입력 → 저장(Ctrl+S)하면 끝입니다.
- 값이 길거나 특수하면 **복붙용으로 값만 코드블록**에 제시한다.
- 그런 다음 사용자가 채우면 되므로, 남은 칸 목록을 **빠짐없이** 준다.

## 표 셀 채우기 요령
- 셀 주소는 `hwp_table_map`이 알려주는 `r행c열`(0부터). 예: `r1c4`. 병합은 `3x1` 식으로 표기됨.
- **라벨 셀 옆/아래의 빈 셀**이 값 칸이다 — fill_by_label이 자동으로 찾지만, 특수한 배치는 `hwp_set_cells(table_index=1, cells={"r1c4":"홍길동"})`로 직접 지정.
- **단위가 이미 있는 칸**("원", "만원" 등): 기존 내용을 지우고 새로 넣으므로 **단위 포함 완성값**을 넣는다. (예: `'350,000,000원'`)

## 체크박스 요령 (★손기입 없이)
- **1순위: `hwp_check_by_label(["동의함","운전자금"])`** — 옵션 단어를 주면 그 옆 네모를 자동으로 체크. **박스가 앞이든 뒤든, □(U+25A1)·☐(U+2610)·`[ ]`(ASCII 대괄호) 세 종류 다 자동.** (`[ ] 동의함` → `[√] 동의함`) 대부분 이거면 됨.
- 결과 표기: `OK(□×N)`/`OK([]×N)` = N개 체크됨(기존 박스를 **교체**하므로 이중박스 안 생김), `이미 체크됨` = 원래 체크 상태, `박스 못 찾음(수동 체크 필요)` = 실패 → 사용자에게 "○○ 옆 네모 직접 체크"로 안내.
- '□ A □ B' 같은 그룹에서 A만 체크해도 **B의 박스는 절대 안 훔친다**(구조 판별 내장).
- 라벨은 `hwp_read_text`에 보이는 그대로. 예: "동의함", "운전자금", "전자상거래 업종".
- **같은 라벨이 여러 곳**이면 전부 체크된다. 특정 위치만 원하면 그 셀을 `hwp_set_cells`로 직접 교체하거나, `hwp_fill_by_label`에 `near`를 써서 그 칸만 바꾼다.
- (구버전 도구) `hwp_check`=□ 뒤만, `hwp_check_after(keyword, position="before"/"after")`=☐ 앞/뒤 — 세밀 제어가 필요할 때만.
- 채운 뒤 **hwp_render로 확인**(엉뚱한 박스가 체크됐는지).

## 표시/숨김
- 기본은 숨김(백그라운드). 사용자가 실시간으로 보고 싶어 하면 `hwp_show_window(show=true)`로 한/글 창을 띄운다.

## 자주 겪는 문제
- **보안 승인창**: 보안모듈이 등록돼 있으면 안 뜬다. 뜨면 `RegisterModule` 실패 상태 → 사용자에게 안내(대개 이미 해결돼 있음).
- **프로세스 잔류**: 작업 끝나면 `hwp_close`. 필요시 사용자 안내로 `taskkill /F /IM Hwp.exe`.
- **값 중복**(원원 등): 예전 버그. 지금 도구는 셀을 비우고 넣으므로 발생 안 함. 보이면 render로 확인 후 재작업.

## 도구 요약 (20개)
- 문서: `hwp_open` `hwp_new` `hwp_read_text` `hwp_save` `hwp_save_as` `hwp_close` `hwp_status`
- 텍스트: `hwp_replace` `hwp_fill` `hwp_insert_text`
- 표: `hwp_table_map` `hwp_set_cells`
- 체크박스: `hwp_check` `hwp_check_after`
- 누름틀: `hwp_list_fields` `hwp_fill_fields`
- 확인/표시: `hwp_render` `hwp_show_window`
- 안전(가역성): `hwp_list_backups` `hwp_restore_backup`
