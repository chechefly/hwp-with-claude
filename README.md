# hwp with claude

**Claude로 한글(.hwp) 문서를 자동으로 작성·편집하세요.**
표 채우기, 체크박스, 신청서·양식 자동완성까지 — 말로 시키면 Claude가 한/글을 직접 조종합니다.

> 한국에서 제일 많이 쓰는 한글(HWP) 파일을 AI가 못 건드리던 문제를 해결합니다.
> Claude가 실제 한/글 프로그램을 조종해 서식·표·이미지를 그대로 유지하며 편집합니다.

---

## ✨ 이런 걸 할 수 있어요

- "이 신청서 열어서 사업자정보·연락처 채워줘"
- "자격요건 체크박스 다 체크해줘"
- "표에 이 금액들 넣고 PDF로 저장해줘"
- "방금 채운 거 이미지로 보여줘" → Claude가 렌더링해서 확인시켜줌

## 🧰 준비물 (설치 전 확인)

| 필요한 것 | 설명 |
|---|---|
| **Windows** | 한/글이 Windows 전용이라 필수 (Mac ❌) |
| **한/글(HWP) 프로그램** | PC에 설치돼 있어야 함 |
| **Python** | 없으면 https://www.python.org/downloads/ 에서 설치 (설치 시 "Add Python to PATH" 체크) |
| **Claude 데스크톱 앱** | Claude Desktop / Cowork / Claude Code |

## 🚀 설치 (3단계)

1. 이 저장소를 **Download ZIP** → 압축 풀기 (또는 `git clone`)
2. **모든 Claude 앱을 완전히 종료**한 뒤, `install.bat` **더블클릭**
   - 알아서 필요한 패키지 설치 + Claude에 자동 등록됩니다
3. **Claude 데스크톱 앱을 다시 실행**

끝! 이제 새 채팅에서 아래처럼 시켜보세요.

## 💬 사용법 (그냥 말로)

```
C:\경로\신청서.hwp 열어서 성명·주소·연락처 채워줘
```
Claude가 알아서: 구조 파악 → 채우기 → 확인(이미지) → 저장 → 파일 반납.

## 🔄 업데이트

- 새 버전이 나오면 Claude가 `hwp_version`으로 알려줍니다.
- 업데이트: 최신 ZIP 다시 받아 `install.bat` 재실행 (또는 `git pull`).

## 🔒 안전 & 개인정보

- **원본 자동 백업**: 열기·저장 시 원본을 `.hwp_backups`에 자동 보관 → 언제든 되돌리기(`hwp_restore_backup`).
- **로컬에서만 동작**: 파일이 인터넷으로 나가지 않습니다. 전부 본인 PC 안에서 처리.
- **보안모듈 안내**: 자동화 시 뜨는 한/글 파일접근 승인창을 없애기 위해 `FilePathCheckerModule.dll`을 등록합니다(오픈소스 표준 모듈). 이는 자동화 편의를 위한 것이며, 신뢰하는 도구에만 쓰세요.

## ⚠️ 한계
